# replay-rs v0.1.0 — Replay buffer для Linux / Wayland

Первый релиз replay-rs: локальный рекордер на Rust, который хранит последние
секунды экрана в памяти и сохраняет их в MP4 по команде — без повторного
кодирования видео. Основная целевая среда — KDE Plasma / Wayland.

## Возможности

- Кольцевой видеобуфер с ограничениями по длительности и памяти.
- Сохранение кнопкой, глобальным хоткеем, через трей или `replay-rs --save`.
- Тёмный интерфейс с бирюзовыми акцентами, статусом записи и заполнением буфера.
- Библиотека клипов с превью, датой, размером и подтверждением удаления.
- Системный звук и микрофон с отдельной громкостью и общей звуковой дорожкой.
- H.264 через VA-API или программный x264; AAC либо Opus для звука.
- Фоновая работа, установка для текущего пользователя и автозапуск.
- Руководство по установке, диагностике и работе нескольких пользователей Linux.

## Готовая сборка Linux x86_64

Скачайте `replay-rs-v0.1.0-linux-x86_64.tar.gz` и `SHA256SUMS` из вложений
релиза в один каталог. Затем выполните:

```bash
sha256sum -c SHA256SUMS
tar -xzf replay-rs-v0.1.0-linux-x86_64.tar.gz
cd replay-rs-v0.1.0-linux-x86_64
./packaging/install.sh
```

Сборка использует системные библиотеки; совместимость с другими дистрибутивами
не гарантируется. Если бинарь не запускается из-за версий библиотек,
соберите приложение из исходников.

## Установка из исходников

В каталоге проекта:

```bash
cargo build --release --locked
./packaging/install.sh
```

Для обновления сначала остановите установленную версию командой
`replay-rs --quit`, затем выполните сборку и установку заново.
Настройки и клипы сохраняются. Запускайте приложение из меню рабочего стола.

## Ограничения

- Требуются системные библиотеки GStreamer и соответствующие плагины;
  приложение не является автономным статическим бинарём.
- Аппаратное кодирование зависит от GPU и драйвера VA-API.
- Поддержка захвата и хоткеев зависит от порталов рабочего окружения.
- Хоткей нужно назначить через системный редактор; предлагается `Ctrl+Alt+S`.
- Крестик сворачивает окно. Полный выход — из трея или через `replay-rs --quit`.
- Смена фактического аудиокодека требует перезапуска приложения.
- Совместной сетевой библиотеки и аккаунтов внутри приложения нет.
