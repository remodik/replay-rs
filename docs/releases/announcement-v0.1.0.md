## Текст анонса

Выпустил replay-rs v0.1.0 — рекордер с replay-буфером для Linux / Wayland,
ориентированный на KDE Plasma.

Он хранит последние секунды экрана в памяти: нажимаешь кнопку или хоткей —
получаешь MP4 без повторного кодирования видео. Есть системный звук,
микрофон, работа в фоне и библиотека клипов с превью.

В интерфейсе — тёмная тема, бирюзовые акценты и наглядный статус буфера.
В README — установка, первый запуск и решение типичных проблем.

Проект написан на Rust с egui и GStreamer. Для работы нужны системные плагины
и поддержка порталов рабочего окружения. Буду рад отзывам и сообщениям об ошибках.

Релиз: https://github.com/remodik/replay-rs/releases/tag/v0.1.0
