# replay-rs v0.2.0-beta.1 — первая сборка для Windows 10 / 11

Бета-версия с Windows-backend. Сборка, тесты и упаковка выполняются в GitHub
Actions на Windows, но ручной прогон на Windows 10 и 11 ещё не проведён,
поэтому релиз помечен как pre-release. Linux-версия — по-прежнему v0.1.0.

## Что нового

- Захват основного или выбранного монитора через Direct3D 11 / DXGI.
- H.264 через программный `x264enc`, сохранение MP4 без перекодирования.
- Системный звук через WASAPI loopback и микрофон через WASAPI.
- Хоткей `Ctrl+Alt+S`, меню в области уведомлений, команды `--save` и `--quit`.
- Установщик PowerShell для текущего пользователя: ярлык в «Пуске» и автозапуск.

## Установка

1. Установите GStreamer **MSVC x86_64 Runtime**, вариант **Complete**
   (проверялась версия 1.26.10). DLL GStreamer в архив не входят.
2. Скачайте `replay-rs-v0.2.0-beta.1-windows-x86_64.zip` и `SHA256SUMS`
   из вложений релиза в один каталог.
3. В PowerShell из этого каталога:

   ```powershell
   (Get-FileHash .\replay-rs-v0.2.0-beta.1-windows-x86_64.zip -Algorithm SHA256).Hash.ToLower()
   Get-Content .\SHA256SUMS
   Expand-Archive .\replay-rs-v0.2.0-beta.1-windows-x86_64.zip -DestinationPath .\replay-rs
   Set-Location .\replay-rs
   powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\install-windows.ps1
   ```

Права администратора не нужны. Подробности, параметры установщика, обновление
и удаление — в `docs/windows.md` внутри архива.

## Ограничения

- Бинарь не подписан: Windows может показать предупреждение SmartScreen.
- Аппаратное кодирование (NVENC, QSV, AMF) пока не поддерживается;
  программный H.264 нагружает CPU.
- Крестик окна завершает запись; для фоновой работы используйте `--headless`.
- Захват защищённого контента, экрана UAC и работа через RDP не гарантируются.

Сообщения о проблемах на Windows особенно полезны для этой беты.
